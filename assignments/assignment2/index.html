Scenario — Fraud Detection for Online Payments

An online payment company wants to detect fraudulent transactions.

For each transaction, a Machine Learning model outputs:

\[ p = P(\text{fraud}=1 \mid x) \]

where:

  • 1 = fraudulent transaction;
  • 0 = legitimate transaction.

The company has developed two candidate classifiers:

  • Model A — Logistic Regression
  • Model B — Decision Tree

Both models are evaluated on the same validation set of 5,000 transactions.

The validation set contains:

100 fraudulent transactions
4,900 legitimate transactions

Their results at the default threshold \(t=0.50\) are:

Model A — Logistic Regression

  • correctly detected frauds: 82
  • missed frauds: 18
  • legitimate transactions incorrectly flagged: 120

Model B — Decision Tree

  • correctly detected frauds: 91
  • missed frauds: 9
  • legitimate transactions incorrectly flagged: 310
NotePositive class

For this assignment:

\[ \text{Positive class} = \text{Fraud} \]

Therefore:

  • TP = correctly detected fraud;
  • FN = missed fraud;
  • FP = legitimate transaction incorrectly flagged;
  • TN = legitimate transaction correctly accepted.

Part II — Calculate and Interpret the Metrics

Use:

\[ Accuracy = \frac{TP+TN}{TP+TN+FP+FN} \]

\[ Precision = \frac{TP}{TP+FP} \]

\[ Recall = \frac{TP}{TP+FN} \]

\[ Specificity = \frac{TN}{TN+FP} \]

\[ F_1 = 2\frac{Precision\times Recall}{Precision+Recall} \]

NoteThreshold changes decisions, not the learned probabilities

Changing the threshold does not retrain the classifier.

It changes the rule used to convert a predicted probability into a final class decision.

Your recommendation:

ImportantSeparate selection from final evaluation

A sound workflow is:

\[ \boxed{ \text{Train} \rightarrow \text{Validate / Select} \rightarrow \text{Final Test} } \]

The final test set should answer:

“How well does the already selected system generalize?”

not:

“Which system should we choose?”
