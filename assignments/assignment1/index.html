CLO1: Explain the fundamental concepts of machine learning, including learning paradigms, data representation, model assumptions, and evaluation principles.

This is an individual assignment.

The purpose of this assignment is to assess whether you can take an unfamiliar real-world problem and translate it into a valid Machine Learning formulation.

You will need to reason about:

  • the learning paradigm and task type;
  • observations, features, and target;
  • what information is available at prediction time;
  • training, validation, and test data;
  • generalization;
  • simple baselines;
  • underfitting and overfitting;
  • data leakage.
ImportantAssessment principle

This assignment is not mainly about memorizing definitions.

You are expected to make defensible modeling decisions, justify them from the scenario, and identify information that would make an evaluation invalid.

Scenario — Early Academic Support System

A university wants to build a Machine Learning system that identifies students who may need additional academic support.

The system will be used at the end of Week 3 of a course.

For each currently enrolled student, the system should estimate whether the student is likely to successfully complete the course.

Historical university records contain information such as:

  • attendance percentage during the first three weeks;
  • diagnostic quiz score;
  • number of LMS sessions during the first three weeks;
  • number of submitted lab activities during the first three weeks;
  • previous cumulative GPA;
  • program of study;
  • year of study;
  • final course grade;
  • final exam mark;
  • whether the student eventually completed the course successfully;
  • student ID;
  • student name.

For this assignment, define:

successfully completed = 1
did not successfully complete = 0

The university intends to use data from previous semesters to develop the model and then use the model for students in a future semester.

NotePrediction-time rule

The model makes its prediction at the end of Week 3.

A feature is valid only if its value would genuinely be available when the prediction is made.
