Welcome

This course develops the foundations of Machine Learning (ML) through data understanding, preprocessing, supervised learning, model evaluation, neural networks, clustering, and dimensionality reduction.

The course combines:

  • conceptual understanding;
  • data analysis and preprocessing;
  • algorithmic and mathematical reasoning;
  • practical implementation in Python;
  • experimental model comparison;
  • evaluation, interpretation, and decision-making.

The objective is not only to fit models, but to understand how they learn, how data representation affects them, how generalization should be evaluated, and how model decisions should be justified in context.

Course at a glance
Learning format: lectures, guided labs, individual assignments, quizzes, exams, and a group project
Core reference: James, Witten, Hastie & Tibshirani, An Introduction to Statistical Learning with Applications in Python, 2023
Main practical environment: Python and Jupyter Notebook

Practical Labs

Hands-on work that connects data, algorithms, experiments, and interpretation.

The practical sequence uses Python and Jupyter Notebook to turn Machine Learning concepts into observable model behavior. Labs cover problem formulation, data quality, preprocessing, regression, classification, evaluation, decision trees, KNN, neural networks, clustering, and PCA.

  • Predict important model behavior before execution.
  • Connect code to algorithmic calculations and internal model logic.
  • Compare preprocessing choices, models, thresholds, and hyperparameters.
  • Debug faulty workflows and interpret results using appropriate evidence.

How to Succeed

A practical workflow to use throughout the course.

  • Understand the problem before fitting a model. Identify the observation, features, target, prediction time, and evaluation goal.
  • Prepare data deliberately. Treat missing values, scaling, encoding, outliers, and feature engineering as modeling decisions.
  • Predict before execution. State what you expect a model, threshold, or hyperparameter change to do and explain why.
  • Separate training, validation, and final testing. Use validation evidence for decisions and preserve the test set for final evaluation.
  • Interpret more than one metric. Connect errors and performance measures to the real-world problem.
  • Explain why. The course rewards reasoning and interpretation, not only successful code or high scores.
